Bitácora de Decisiones

Cada cambio de comportamiento del sistema, con el porqué detrás. No es una lista de código: es el registro de las decisiones de negocio, para que nadie revierta por accidente algo que se decidió a propósito.

Ninguna decisión coincide con esa búsqueda.

La fuente de verdad es DECISIONS.md en el repositorio — ahí es donde el asistente lee antes de cambiar comportamiento, y donde te avisará si una petición nueva contradice una decisión anterior. Esta página es una vista de ese archivo para consultarla y compartirla.
